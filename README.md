## 怎么玩？

凭直觉回答 13 道社交情境题。每个选项按烧心程度累计 **0–3 分**，总分越高，社交心口越热：

| 总分 | 结果 |
| --- | --- |
| 0–9 | A · 社交清流 |
| 10–19 | B · 懂得留余地的聪明人 |
| 20–29 | C · 状态看老天爷的选手 |
| 30–39 | D · 期待毁灭专家 |

做完可以分享结果链接；想保存画像的话，手机直接截图通常最省心。**本测试仅供娱乐，请勿当真，也不要据此给人打分。**

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

项目使用 React、TypeScript、Vite 和 Tailwind CSS，部署为纯前端静态网页。
